# references/ — reference genomes (symlinks only)

The entries here are **symbolic links** to reference assemblies on the TSCC
cluster. Each target is 2–3 GB, so none of it is stored in this repository.

## Comparative genomes — download from NCBI

These are public assemblies, not data generated by this study. Download each by
its accession from NCBI (https://www.ncbi.nlm.nih.gov/datasets/genome/) and keep
the link name below so `config.sh` resolves.

| Link name | Species | Assembly | Accession |
|---|---|---|---|
| `GRCm39_genome.fna` | Mouse | GRCm39 | **GCF_000001635.27** |
| `human_GRCh38_genome.fna` | Human | GRCh38 | **GCF_000001405.26** |
| `rat_GRCr8_genome.fna` | Rat | GRCr8 | **GCF_036323735.1** |
| `dog_Dog10K_genome.fna` | Dog | Dog10K Boxer Tasha | **GCF_000002285.5** |
| `guineaPig_mCavPor4_genome.fna` | Guinea pig | mCavPor4.1 | **GCF_034190915.1** |
| `nakedMoleRat_genome.fna` | Naked mole-rat | paternal | **GCA_944319725.1** |
| `OctDeg1_genome.fa` | Degu (previous assembly) | OctDeg1 | see manuscript |

Used by the cross-species tandem-repeat comparison
(`06-tandem-repeat-analysis/02_repeat_analysis/check_tandem_repeats_*.ipynb`) via
`config.sh` vars `HUMAN_GENOME_FA`, `RAT_GENOME_FA`, `DOG_GENOME_FA`,
`GUINEAPIG_GENOME_FA`, `NMR_GENOME_FA`, `MOUSE_GENOME_FA`.
