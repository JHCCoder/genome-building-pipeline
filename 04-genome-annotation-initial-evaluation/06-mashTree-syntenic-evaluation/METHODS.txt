Methods — mashtree-ordered synteny plot (Supplemental Figure S4B)
===================================================================

This file describes how the code in this directory builds the synteny plot of
OctDeg2.0 (the degu assembly) with other rodent species, in which the species
are ordered by a mashtree constructed from the Jaccard distance between 21-mer
sets. The relevant scripts are 01_mashtree.sh, 02_mash_distance_tree.sh,
03_ntSynt.sh, and 04_ntsynt_viz.sh.


Ready-to-use paragraph
----------------------

Whole-genome synteny between the degu assembly (OctDeg2.0) and ten other
assemblies (eight rodents plus human and dog outgroups) was detected with
ntSynt v1.0.2 using an approximate maximum sequence divergence of 20% between
input genomes. Synteny blocks were visualized as a ribbon plot with ntSynt-viz
v1.0.0, using OctDeg2.0 as the target genome and normalizing chromosome strands
relative to it. The top-to-bottom order of the species was determined by a
mashtree constructed from the Jaccard distance between 21-mer sets of the input
assemblies; mashtree v1.4.6 (with mash v2.3) was run with both jackknife and
bootstrap resampling (100 replicates each). As an independent distance-based
comparison, a second tree was inferred by sketching each assembly with mash
(k = 21, sketch size 8,000), computing the all-versus-all Jaccard distance
matrix with mash triangle, and performing BIONJ neighbor joining with FastME.


Step-by-step detail
-------------------

1. Species order (mashtree).  The 21-mer sets of the 11 assemblies were
   compared and clustered into a neighbor-joining dendrogram with mashtree,
   run in two resampling modes (01_mashtree.sh):

       mashtree_jackknife.pl --reps 100 --numcpus 8 -- --min-depth 0
       mashtree_bootstrap.pl --reps 100 --numcpus 8 -- --min-depth 0

   mashtree delegates k-mer sketching to mash and uses the default k-mer size
   (k = 21); the tree is therefore built from the Jaccard distance between
   21-mer sets. Tree leaves were relabeled from assembly filenames to display
   species names (rename_tree.py).

2. Alternative distance tree (mash + FastME).  Independently, each assembly was
   sketched with mash at k = 21 and a sketch size of 8,000, and the pairwise
   Jaccard distance matrix was computed with mash triangle
   (02_mash_distance_tree.sh):

       mash sketch <assembly> -s 8000 -p 8
       mash triangle *.msh            # lower-triangular Jaccard distance matrix
       fastme -i all_distances.phy -D 101     # BIONJ tree

   This tree was not used for the final figure; it served as a cross-check of
   the mashtree topology.

3. Synteny detection (ntSynt).  Pairwise whole-genome synteny blocks were
   computed across all 11 assemblies (03_ntSynt.sh):

       ntSynt -d 20 --fastas_list fasta_list.txt -p rodent -t 12

   where -d 20 sets an approximate maximum of 20% sequence divergence between
   genomes (ntSynt uses this to derive its block-size, merge, and window-round
   thresholds).

4. Visualization (ntSynt-viz).  The synteny blocks were drawn as a ribbon plot
   with ntSynt-viz, ordering the species along the y-axis by the mashtree from
   step 1 (04_ntsynt_viz.sh):

       ntsynt_viz.py --blocks rodent.synteny_blocks.tsv \
                     --fais *.fai \
                     --normalize \
                     --ribbon_adjust 0.14 \
                     --scale 1e9 \
                     --name_conversion name-conversions.tsv \
                     --target-genome Degus \
                     --tree mashtree.bootstrap.renamed.dnd

   The --tree argument passes the mashtree newick so that species are drawn in
   mashtree order; --normalize orients chromosome strands relative to the
   target genome (Degus). The plot was generated for both the bootstrap and
   jackknife mashtrees.


Software versions
-----------------

- mash v2.3 (Ondov et al., 2016, Genome Biology)
- mashtree v1.4.6 (Katz et al., 2019, Journal of Open Source Software,
  doi:10.21105/joss.01762)
- ntSynt v1.0.2 (Coombe et al., 2024, bioRxiv, doi:10.1101/2024.02.07.579356)
- ntSynt-viz v1.0.0 (https://github.com/bcgsc/ntSynt-viz)
- FastME (Lefort, Desper and Gascuel, 2015, Molecular Biology and Evolution)
