# Methods context — bulk Hi-C & scMultiome metric comparison (Figure 3, Panels D–G)

Scope: this file covers the bulk Hi-C cis-contact / cis-trans comparison (panels D/E)
and the scMultiome feature-linkage / genes-per-cell comparison (panels F/G). Panels
A–C (whole-genome alignment + repeat overlap) are described in README.md.

## What this section shows

The same biological samples were aligned to both assemblies — the OctDeg1.0
reference and the new OctDeg2.0 (hifiasm-041425) assembly — and per-assembly QC
metrics were compared. For every sample, OctDeg2.0 yields more cis Hi-C contacts
and a higher cis/trans ratio, and more single-cell signal (feature linkages and
median genes per cell), consistent with the new assembly capturing more mappable
(largely repetitive) sequence than OctDeg1.0.

Assemblies:
  - octDeg1 = OctDeg1.0 reference
  - octDeg2 = OctDeg2.0 (hifiasm-041425)

## Bulk Hi-C (Panels D & E)

Samples (n = 4): degu_060302, degu_060303, degu_120106, degu_040604.

Hi-C reads from each sample were aligned independently to OctDeg1.0 and to
OctDeg2.0, and per-sample/per-assembly summary metrics were computed:

  - Cis_Contact    — number of cis (intra-chromosomal) contacts
  - Cis_Trans      — cis/trans contact ratio (intra- vs inter-chromosomal contacts)
  - Read_mapped    — number of reads mapped
  - Pairs_mapped   — number of read pairs mapped

Data:    data/cis_trans_bhic_metrics.txt
Plotting: 03_bhic_cistrans_barplots.py

  - Any filtering applied before counting contacts (MAPQ threshold, PCR-duplicate
    removal, valid-pair extraction, restriction-fragment assignment).

## scMultiome (Panels F & G)

Samples (n = 4): 181_PFC (prefrontal cortex), 181_dHIP (dorsal hippocampus),
6997_dHIP, 7000_PFC.

10x Genomics Multiome (joint ATAC + gene-expression) libraries were processed with
Cell Ranger ARC. Each sample was aligned to both assemblies and the Cell Ranger
ARC summary metrics were compared:

  - "Feature linkages detected"  (Panel F) — number of regulatory element-to-gene
    linkages (ATAC peaks linked to expressed genes).
  - "Median genes per cell"      (Panel G) — median genes detected per cell.
  - "Median high-quality fragments per cell" — in data/fragment_per_cell.txt
    (computed but not plotted).

Data:    data/feature_linkage.txt, data/gene_per_cell.txt
Plotting: 04_scmultiome_metric_barplots.py

[FILL IN from pipeline notes]:
  - Cell Ranger ARC version.
  - Reference construction: both assemblies were built into Cell Ranger ARC
    references (details of the mkref step and any gene annotation used).

## Metric definitions

  Cis contact          contacts between loci on the same chromosome
  Cis/trans ratio      ratio of intra-chromosomal to inter-chromosomal contacts
  Feature linkage      Cell Ranger ARC linkage of an ATAC peak to a target gene
  Median genes/cell    median number of genes detected per cell (Cell Ranger ARC)

## Caption caveats to keep consistent with the figure

  - The caption says "mean genes per cell" for Panel G; the Cell Ranger metric
    (and gene_per_cell.txt) is the MEDIAN genes per cell.
  - The caption's "from 4 Hi-C samples" for Panels F/G is a copy-editing slip —
    feature linkages and genes per cell are scMultiome (10x Multiome) metrics,
    not Hi-C metrics.
